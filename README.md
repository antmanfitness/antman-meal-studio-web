# ANTMAN Meal Plan Studio (GitHub Pages)

Static build of the private Meal Plan Studio.

**Live:** https://antmanfitness.github.io/antman-meal-studio-web/

Data lives in your browser (`localStorage`). Use **Load all clients** once to seed coaching folders (Henri excluded).

Source app: local `/workspace/antman-meal-studio` on the Grok Bot box. PDF archives for meal plans live under `public/reference/` locally and on Drive/Canva — not in this Pages repo.
